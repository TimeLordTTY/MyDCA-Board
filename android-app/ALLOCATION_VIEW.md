# v0.18 Android 配置偏离只读查看

总览进入「配置偏离与止盈观察」，分页读取主人保存的规则，打开详情读取规则与收益观察。情景预览由主人主动点击读取，不自动创建、编辑配置，不提供交易执行入口，不新增权限。

网络契约：GET `/api/v2/allocation-policies?page=...&size=20`、GET `/{id}`、无请求体 POST `/{id}/evaluate`、GET `/{id}/preview`。evaluate 虽使用 POST，但后端 `AllocationPolicyService.evaluate` 为只读事务，不保存评估或修改财务记录；不调用创建、PATCH、订单、结算或入账接口。

比例以小数传输，展示百分比；偏离以百分点展示。收益观察优先级与独立配置偏离不同，因此同时展示后端观察状态和主动获取的情景区间状态。评估时间与预览数据日期分开标明，两次读取可能来自不同快照。缺失数值为 UNKNOWN，合法零值保留。情景包括目标点和最近边界的等额反向假设金额，保留行情与估值日期、价格来源 UNKNOWN 和 NOT_MODELED 警告。

401/403 使用既有认证提示；网络、服务或解码失败清除本次数据并提供人工重试。来源日期缺失/异常及超过三天的快照明确提示。固定说明：规则来自主人配置；情景预览不构成交易建议。

本地验证使用 MockWebServer，不连接真实服务或数据库。单元测试覆盖 Compose 使用的读取状态、权限/空态/网络失败、未知/陈旧状态、阈值边界及请求白名单（包括只读 POST 例外）。真实设备、TalkBack 与目标环境 migration 仍需人工验收；版本和公共状态文档交给 release-hardening。
