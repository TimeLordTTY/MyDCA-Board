# v0.21 数据就绪只读提示

总览的目标与本月预算入口展示个人作用域诊断，进入时读取一次，后续仅手动刷新。
GET /api/v2/data-readiness?scope=PERSONAL&month=设备当前月份；复用 JWT 与 401 会话失效处理。
不指定其他 owner/family，不提供家庭管理员或运维入口。

中文 READY/PARTIAL/UNAVAILABLE/UNKNOWN 与来源详情沿用后端证据。READY 仅表示可读，
不表示目标达标、预算未超支或可以上线。schema 始终提示未知、需人工核验，
不依据 SQL 文件判断部署成功。空证据和未知更新时间明确显示未知，缺失值不当零。

失败保留本会话先前警示，标记旧快照并显示网络、权限或服务错误；重试成功替换快照。
诊断时间未知、异常、在未来或超过 24 小时标记陈旧；来源时效沿用后端逐项判断，
显示来源更新时间供人工核对。本地不持久化，不写规则、预算、账户或账本，不发 SQL 或交易请求。

验证：Compose 使用的状态转换与时间判断单元测试；MockWebServer 覆盖个人 GET、
认证、401/403/503、UNKNOWN/PARTIAL/UNAVAILABLE、空证据、非法响应、作用域不匹配、断网和恢复。
仅本地测试服务器；真实环境、部署状态和真机交互仍需人工验收。
