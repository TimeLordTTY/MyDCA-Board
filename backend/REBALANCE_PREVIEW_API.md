# 再平衡只读情景预览

`GET /api/v2/allocation-policies/{id}/preview`，无请求体，只读取当前用户有权访问的已保存配置；FAMILY 复用家庭管理员校验。停用配置不读取财务数据。

比例使用小数，偏离使用百分点：`(当前权重 - 目标权重) * 100`。分母为人民币现金加持仓市值，不扣负债。输出当前权重、保存的目标/上下限、偏离、数据日期、逐产品价格/估值日期及警告。

`targetScenario` 给出到目标点的情景调整；`bandScenario` 给出到最近边界的情景调整，在区间内为零。正数为选中资产假设增加金额，负数为假设减少金额。其余组合金额始终等额反向，总资产固定；不分配其余组合到各产品。金额四舍五入至分，亚分偏离可能仍存在，不保证舍入后严格到达目标或边界。上下边界均包含，判断使用未舍入金额。

所有量均为数学假设，不是交易建议或可执行金额；不校验现金可用性、资金用途或交易限制，不创建订单、不锁资金、不占份额、不写账本、不保存预览。不依赖 OrderService / SettlementService。相同配置与快照的输出一致，不添加当前执行时间。

行情 UNKNOWN/STALE、缺失日期/分类/市值/份额、现金或持仓汇总不一致时，status 为 UNKNOWN，当前权重、偏离和情景金额为 null。缺失成本不影响仅使用市值的计算；收益观察阈值不参与此计算。

现有快照未提供原始价格来源，逐产品 priceSource 和 PRICE_SOURCE 警告为 UNKNOWN，不推测供应商。税、费用、滑点、交易限制和外汇为 NOT_MODELED；继承雷达警告。无新增 migration，测试仅使用 mock，无数据库连接。
