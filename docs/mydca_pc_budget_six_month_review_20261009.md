# PC 近六个月预算回顾 · 2026-10-09

任务：`task-mydca-pc-budget-six-month-review-20261009`。在目标与预算中心的“月度预算”标签增加可展开/关闭的只读回顾，不命名新版本。

## 实际实现

- `BudgetSixMonthReview.vue` 与 `budgetReviewModel.ts`：默认本地日历本月向前连续五个月，以月初做月份运算，兼容跨年、闰年和月末。展开不会请求，必须点击加载/刷新；筛选变化后必须重新加载。
- 仅复用预算列表与对比 GET；共享 API 新增可选 AbortSignal，不改变原单月 CRUD 行为。最多5页（每页20份）、30份对比，并发最多3个，一次回顾总请求不超过35个。扫描未结束或对比数量超限则清空并提示，不把截断扫描当作没有预算。
- PERSONAL/FAMILY、币种过滤只针对后端授权返回的记录，不推断身份或提升权限。不同预算逐份并列，名称及ID均可识别，同月不相加，不合并为整月/家庭总现金流。覆盖口径仅为既有分类预算；家庭仍是当前用户在当前家庭的后端流水口径。
- 完整扫描中的空月份显示“未创建预算（当前作用域与币种）”，金额未知。只有 quality=OK 且实际收入、支出、结余、剩余预算均为有限数值、超支为布尔值，才显示实际读数及超支状态。PARTIAL/UNKNOWN/UNAVAILABLE 与任一缺失实际字段保留未知边界，已知项目来源另放可键盘打开的 details，不形成实际趋势。完整API零值可显示为零。
- 计划预留单列，计划结余沿用API已扣预留结果，不表示真实转账、占用或实际支出。不做额外汇总或数学推断。
- 表格包含月份、预算、币种、口径、计划与实际、完整性、超支、未匹配流水、warnings和读取时间；时间是客户端逐份收到对比的时间，API未提供账务快照时间，不冒充统一数据快照。表格带caption、行列表头、可聚焦横向滚动容器、中文加载/错误播报及人工重试。
- 关闭、取消、筛选、父页面刷新/编辑/选择、标签卸载、用户/家庭信息或Token变化会清空回顾并取消请求。代次校验和AbortSignal共同阻止过期结果回填；失败清空且停止继续调度，整体30秒超时可人工重试。原共享401/403跳转登录行为保留。
- 点击独立预算按钮回到已有单月详情与对比逻辑。回顾不调用写API、不持久化敏感详情、不新增后端/数据库/图表依赖。
