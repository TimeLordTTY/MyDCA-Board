# v0.14 只读策略实验室

PC「策略实验室」可从受控历史净值 CSV 目录选择数据和白名单策略，设置有限数值参数，查看收益、年化、回撤、投入、期末资产、现金、交易次数及相对定期投入基准的差异。Android「回测」仅查看服务器内存中的最近结果，不发起回测。历史回测不代表未来表现。

后端接口为 `GET /api/v2/backtest-lab/datasets`、`GET /recent`、`POST /runs`，都沿用已有 JWT 认证。数据目录由服务端 `backtest.data-root` JVM 属性配置，默认从 `backend/` 工作目录解析 `../data/backtest`；只接受目录一级中符合 `[A-Za-z0-9_-]{1,80}.csv` 的普通文件。部署时由管理员准备离线 CSV，列为 `date,nav`，不使用真实账户或数据库。执行脚本固定为仓库的 `scripts/backtest/run_backtest.py`，Python 命令可通过 `backtest.python` 属性配置。请求不能指定命令、脚本路径或数据根目录。

策略白名单：`pure_sip:1`、`ma_enhanced:1`、`profit_recycle:1/2`。参数白名单、数值边界、20 MB 数据上限、20 秒执行上限与 2 MB 响应上限在服务端校验。同一登录用户的相同数据内容与策略参数重复请求复用内存缓存；文件内容变化会失效。最近结果按登录用户隔离。最多保留 100 个缓存条目，服务重启后最近结果清空。运行结果不进入订单、结算、账本或交易服务；没有数据库迁移。

后端非法数据、策略、参数和超时会返回中文原因。PC 有加载、空态、失败态；Android 有空态和失败态。结果仅作历史分析。
