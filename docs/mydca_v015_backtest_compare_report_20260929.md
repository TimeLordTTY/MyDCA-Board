# v0.15 回测历史对比与报告导出

PC 策略实验室可分页选择 2 至 5 条成功的历史回测记录，同屏查看总收益、年化、最大回撤、投入、期末资产、现金、交易次数、相对基准差异和数据区间。失败记录不能选择。数据集 SHA-256、日期区间或策略版本不一致时，页面和导出报告均显示警告。

`POST /api/v2/backtest-lab/runs/compare` 接受 `{ "runIds": ["历史 UUID", "历史 UUID"] }`。后端逐条按当前用户及家庭作用域读取持久历史，拒绝不可见、失败、重复或数量不合规的记录。返回 JSON 报告及其中的 `markdown` 字段；PC 可分别下载 JSON 和 Markdown。报告包含生成时间、历史 run ID、数据集 hash、策略与版本、规范化参数、引擎版本、指标、基准差值及“历史回测不代表未来表现”。报告仅从受控字段构造，不包含数据集文件名、原始 CSV、绝对路径或 Token。

现有回测结果不保存资产曲线，因此此版本没有曲线对比，也不会为绘图再次执行回测程序。对比接口只读历史文件，不连接数据库，不创建订单或交易。
