# v0.17 Android 只读风险观察中心

总览新增「打开风险观察中心」。固定展示「仅供观察，不构成交易建议」。仅前台读取已保存的规则、提醒和评估历史，不触发评估、编辑、ACK/MUTE、订单、结算或账本动作；未增加权限、后台任务或本地证据持久化。

## 展示与分页

规则每页 20 条；当前提醒汇总本页规则各最近 20 条事件，按 CRITICAL / WARNING / INFO 分组，支持 OPEN、RESOLVED、全部（含 ACKNOWLEDGED/MUTED）过滤。过滤作用于已读取记录；空态明确不代表没有风险。每条提醒可进入对应规则详情。完整历史按规则逐页读取，每页 20 条，页面提供上一页/下一页。

详情显示规则类型、作用域、产品/类别、方向、目标、阈值、备注，以及事件原始状态、命中原因、观察值、来源时间、评估时间。比例保留服务端小数口径（0.1 = 10%），STALE 阈值为天。历史包含 UNKNOWN 和未命中快照。UNKNOWN/null 不转换为零或解除；来源日期缺失、未来日期及超过 3 天各有提示。新鲜度按设备本地日期计算，仅是观察提示，不替代后端规则评估。

刷新只发送 GET，不意味着数据重新评估。加载/失败清除旧证据，401 使用现有会话失效处理，403、服务失败、网络/数据不可读明确显示中文错误并支持手动重试。规则查询失败不伪装成空态；部分规则事件读取失败不显示不完整汇总。

## 接口与部署边界

仅新增客户端 GET `/api/v2/risk-watch-rules`、`/{id}/events`、`/{id}/snapshots`，复用认证网络层。依赖 v0.17 风险观察与提醒历史后端及部署方人工部署迁移；本任务未连接数据库、未部署、未修改财务记录。版本号和 CI 制品约定沿用现有发布版本；此功能增量未产生 CI 制品。
